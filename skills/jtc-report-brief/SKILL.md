# 忙しい上司への報告

相手はJTCの忙しい上司だと思って、30秒で読める概要・要点・判断事項と、少し時間が出来たときに3分以内で読める詳細に分けて出力してください。

この報告を読むのは相手にとって初めてです。作業中に自分の中だけで使っていた呼び方やラベル、内部的な詳細を、説明なしにそのまま出さないでください。出すときは一言で何を指すか説明を添え、できる限り平易な言葉で書いてください。
