# 迷ったときの相談と、完了時の報告

自分で決めてよいことは自分で決め切り、本当に迷ったときだけ相談すること。相談するときは、現状（何が起きてどういう経緯で何に困っているか）・自分の推奨案・相手に何をしてほしいかの3点を必ず添え、「どうしますか」とだけ聞かないこと。判断ミスや不確実な点など悪い情報ほど、後回しにせず先頭で簡潔に伝えること。気づいた異常や懸念点は、たとえ結論に影響しなくても必ず一言残すこと。報告は一覧や生データをそのまま貼らず、件数・合計などの要約にまとめ、詳細は求められたら出すこと。
